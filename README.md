# API Mock Response Builder (`ts-react-api-mock-builder`)

A developer REST API mock builder and request tester built with React, TypeScript, Vite, and Tailwind CSS. Define custom endpoints, configure JSON payloads, status codes, and simulated latency, and test them live.

## Features

- **Route Management:** Add, configure, and delete REST endpoints (GET, POST, PUT, DELETE).
- **Live Response Tester:** Simulate network requests with realistic latency delays and response payloads.
- **Strict TypeScript Types:** Fully typed interface contracts across all components.

## Setup & Running

1. Install dependencies:
   ```bash
   cd ts-react-api-mock-builder
   npm install
   ```
